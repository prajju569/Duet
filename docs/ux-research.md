## 2. What makes the leaders feel good (and what we copied)
1. **Nothing is ever lost:** drafts, retry, unread divider, search. → built all four.
2. **One gesture, many actions:** a long-press opens one clean menu. → rebuilt ours the WhatsApp way.
3. **Presence without pressure:** last seen, typing / recording. → built.
4. **Control over noise:** mute, archive, pin, badge. → built.
5. **Music as a social object** (Spotify Jam, Instagram music stickers). → Duet's edge: song cards, dedications, moments, invites, "Now playing".
6. **Rituals** (couples apps: daily question, countdowns, "thinking of you"). → built question of the day + countdown; 🥹 / 💭 already there.
